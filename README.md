# Super-Store-excel-Dashboard
A data analytics project using the Super Store dataset to uncover insights from sales, profit, returns, discounts, products, and regional performance. It identifies growth opportunities, profitability challenges, and operational issues, with recommendations for pricing, inventory, returns, and resource allocation to support data-driven decisions.
